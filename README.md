# Pet-First — лабораторная работа №3

Главная страница свёрстана по предоставленному Figma-макету **Pet shop landing page design (Community)**. Структура выполнена семантическими HTML5-тегами, стили вынесены в отдельный файл.

## Состав проекта

- `index.html` — разметка главной страницы.
- `styles.css` — оформление desktop-версии и адаптация для узких экранов.
- `images/` — фотографии и текстура из Figma.
- `js/script.js` — мобильное меню и демонстрационная обработка формы подписки.

## Что учтено в оформлении

- Основная палитра Figma: кремовый `#EBE3CC`, тёмно-синий `#062D3E`, бирюзовый `#189CAB`, оранжевый `#ED5C01`, жёлтый `#FBBD08`.
- Сохранены пропорции секций макета: hero, оранжевая полоса с категориями питомцев, услуги, бирюзовый блок, отзывы, подписка и подвал.
- Карточки услуг получили жёлтую и контурные формы, а вместо фотографий в иконках используются векторные пиктограммы.
- В блок отзывов добавлены декоративная цитата, лента-индикатор и светлая подложка текста.
- В блок подписки добавлены декоративные линии и оригинальная фотография собаки.
- Имена классов и файлов на английском языке, у фотографий прописан `alt`.

## Запуск

1. Распакуйте архив в отдельную папку.
2. Откройте `index.html` в браузере.
3. Для редактирования можно открыть папку проекта в VS Code и использовать Live Server.

Установка зависимостей и сборка не требуются. Шрифт Josefin Sans загружается через Google Fonts; без Интернета браузер использует системный шрифт-замену.

## Проверка валидности

- HTML: https://validator.w3.org/ — **Validate by File Upload**, загрузить `index.html`.
- CSS: https://jigsaw.w3.org/css-validator/ — **By File Upload**, загрузить `styles.css`.

Локально проверены пути всех изображений, якорные ссылки, уникальность ID, синтаксис CSS и JavaScript. Онлайн-валидаторы W3C из этой среды не запускались.

## Примечание

В исходном Figma-файле используется шрифт Neue Montreal для отдельных надписей. Отдельный файл этого шрифта в предоставленных материалах отсутствовал, поэтому для таких надписей используется Josefin Sans / системный sans-serif. Для адаптивного отображения добавлены медиазапросы; отдельные mobile-фреймы в `.fig` не обнаружены.

## Что исправлено при перепроверке вёрстки

- **Блок с питомцами**: ряд из 12 фото и пуг вылезали за правый край экрана. Теперь это CSS Grid, который сам подстраивается под ширину; на узких экранах (до 900 px) пуг выводится сверху, фото идут ниже в 2 ряда.
- **Карточки услуг**: третья карточка («Cloths») обрезалась справа и была недоступна. Теперь три карточки равной ширины в сетке, текст внутри идёт обычным потоком (без абсолютных координат), кнопки выровнены по низу, карточки опираются на нижний край блока.
- **Собака в блоке подписки**: изображение растягивалось (`object-fit: fill`, пропорции 507×800 сжимались в 407×381). Пропорции восстановлены, поводок снова соединяется с собакой.
- **Отзывы**: звезда с кавычкой больше не «рвётся» пунктирной рамкой, хвостик у облачка заменён на аккуратный, такса сидит на карточке и не наезжает на заголовок, кнопки-стрелки и точки выровнены по ширине карточки. Декоративные элементы скрыты от скринридеров.
- **Шапка на 760–1000 px**: пункт «Blog» прятался под кнопкой Sign up; заголовок hero упирался в фото собаки. Уменьшены отступы меню и размер заголовка.
- **Подвал**: логотип и меню выровнены по одной линии, лишняя пустота убрана.
- **Контраст и доступность**: бирюзовый текст на кремовом фоне (меню, «Available in select states») затемнён до 4.6:1, текст на бирюзовой секции — белый, добавлены видимые `:focus-visible`-рамки.
- Проверено на ширинах 320–1920 px: горизонтальной прокрутки нет, ошибок JS нет, якоря, ID и пути к картинкам корректны.
- **Блок услуг на широких экранах**: заголовок «Our Service», жёлтая завитушка и бирюзовый прямоугольник привязаны к сетке карточек (раньше разъезжались к краям окна на 1920 px).
